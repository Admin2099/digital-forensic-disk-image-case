# Digital Forensic Disk Image Case Study

## Insider Threat and Data Exfiltration Dataset

---

## Overview

This repository contains a digital forensic disk image dataset designed for cybersecurity and forensic analysis.

The dataset represents an insider threat scenario where suspicious user activity may involve:

Financial irregularities
Data exfiltration
Unauthorized file handling

File system structure analysis
Metadata investigation including timestamps and ownership
Identification of suspicious files
Detection of compressed or hidden data
User activity reconstruction
